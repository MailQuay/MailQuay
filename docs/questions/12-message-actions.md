# 12 阅读器操作与回复格式

## 已确认

- 阅读器顶部主操作: 回复, 转发, 标记, 本地归档, 删除.
- 归档是本地归档, 在本地额外保存一份, 不删除远端原邮件.
- 删除默认移动到垃圾邮件文件夹, 由邮件服务自动清理.
- 设置中可以改为本地删除队列: 填写保留天数, 写入数据库, 到期后删除邮件并同步.

## 当前默认

- 主操作: 回复, 转发, 标记, 本地归档, 删除.
- 引用: HTML 使用引用块, 纯文本使用 `>` 前缀, 默认保留原文.
- 签名在引用上方, 引用在下方.
- v1 不做稍后提醒.
