# 12 阅读器操作与回复格式

## 已确认

- 阅读器顶部主操作: 回复, 转发, 标记, 本地归档, 删除.
- 归档是本地归档, 在本地额外保存一份, 不删除远端原邮件.
- 删除默认只把邮件移动到已删除文件夹, 由邮件服务自动清理; 不提供本地删除队列或保留天数.
- 在已删除文件夹中再次删除时通过 IMAP 永久删除.

## 仍未回答

1. 不提供"全部回复"入口.
2. 回复时默认是否引用原文?
3. v1 是否做稍后提醒?

## 当前默认

- 主操作: 回复, 转发, 标记, 本地归档, 删除.
- 引用: HTML 使用引用块, 纯文本使用 `>` 前缀, 默认保留原文.
- v1 不做稍后提醒.
