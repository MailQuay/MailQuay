# 07 本地标记与账号删除保留

## 已确认

- 标记只存在本地, 不导入也不回写 IMAP `\Flagged`.
- 标记的唯一作用是方便用户在本地找到邮件, 没有其他业务含义.
- 标记邮件在本地保留完整正文和附件, 即使账号后来被删除.
- 删除邮箱账号时, 异步清理该账号的邮件和索引, 但默认不删除已标记邮件.
- 是否保留标记邮件是设置项, 默认开启.

## 仍未回答

1. 账号删除后, 用户取消某封保留邮件的标记时, 应该删除本地副本, 还是保留为无归属的本地邮件?
2. 账号删除后保留的标记邮件, 是否只出现在"标记"和搜索结果, 还是也进入"全部"视图?
3. 标记时如果完整正文或附件拉取失败, 通知后重试即可, 还是需要阻止标记成功?

## 当前默认

- 取消保留邮件的标记时, 弹出确认; 选择删除本地副本才删除, 否则继续保留并保持标记.
- 保留邮件只出现在"标记"和搜索结果, 不进入"全部".
- 标记先成功, 后拉取完整内容; 拉取失败进入任务环并重试, 不撤销标记.
- 标记邮件的内容和附件不参与普通账号清理.
