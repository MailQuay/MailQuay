# 11 写邮件窗口的身份选择方式

## 已确认

- 写邮件默认使用应用内二级窗口 (浮层), 不需要离开当前邮件页面.
- 设置中可以改为打开浏览器新窗口, 使用独立 `/compose` 页面; 草稿 ID 通过 `window.name` 传递, 不使用路径参数或查询参数.

## 仍未回答

1. 身份选择放在左上角发送按钮的弹层里, 还是单独放一个发件人下拉框?
2. 是否需要同时保留"发送按钮下拉选择身份"和"发件人下拉框"两种入口?

## 当前默认

- 左上角是发送按钮和下拉箭头; 点击箭头打开身份选择弹层.
- 弹层支持搜索, 按账号分组, 显示 `显示名 <邮箱>`.
- 发送按钮主区域使用当前身份.
- 发送前可以切换任意身份; 回复默认使用原邮件所属账号的默认身份.
