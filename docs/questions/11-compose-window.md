# 11 写邮件窗口的发件人选择方式

## 已确认

- 写邮件默认使用应用内二级窗口 (浮层), 不需要离开当前邮件页面.
- 设置中可以改为打开浏览器新窗口, 使用独立 `/compose` 页面; 草稿 ID 通过 `window.name` 传递, 不使用路径参数或查询参数.
- 发件人一行选择邮箱账号; 回复默认使用原邮件所属账号, 发送前可以切换.
- Reply-To 在写邮件窗体中编辑, 默认使用账号的默认 Reply-To, 未配置时使用发件人邮箱.

## 仍未回答

无.

## 当前默认

- 发件人一行显示 `默认发信名称 <邮箱>`, 点击打开发件账号弹层, 每个邮箱账号一项.
- 发送按钮直接发送当前草稿; 下拉箭头只提供定时发送.
- 切换发件账号时, Reply-To 跟随该账号的默认值.
