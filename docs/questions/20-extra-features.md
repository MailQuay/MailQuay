# 20 通知, 联系人, 加密等扩展

## 问题

以下功能哪些进入 v1?

## 选项

- 系统通知: A 不做, 只显示未读; B 浏览器通知; C Web Push.
- 收件人自动完成: A 只从本地收发历史; B 增加通讯录; C 不做.
- 邮件规则: A 不做; B 只做服务商侧规则说明; C 本地过滤规则.
- 端到端加密: A 不做; B 支持 PGP; C 支持 S/MIME.
- 移动端: A 列表和阅读器分视图; B 只做桌面宽度.
- 快捷键: A 做基础 j/k/Enter/r/a/e/c//; B 不做; C 可自定义.

## 当前默认

- 系统通知: A.
- 自动完成: A, 从本地收发历史提取, 不建通讯录.
- 邮件规则: A.
- 端到端加密: A.
- 移动端: A.
- 快捷键: A, 基础集合, 暂不支持自定义.

## 影响

每一项都会增加独立的界面和测试面. 通知和加密尤其涉及权限, 密钥和隐私.
