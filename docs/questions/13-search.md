# 13 搜索范围与组合条件

## 已确认

- 搜索模式可选"标题"或"全部".
- 可选条件: 账号, 文件夹, 收件人, 发件人, 是否有附件.
- 支持自由文本和这些条件组合, 例如账号 `me@yeqing.im`, 发件人 `service@intl.paypal.com`, 全部内容搜索 `advin`, 并且有附件.

## 仍未回答

1. 本地没有拉取正文的邮件, 是否继续用 IMAP 服务端搜索补结果?
2. 收件人条件是否同时匹配 To, Cc 和 Bcc, 还是只匹配 To?
3. 搜索结果是否包含本地归档?
4. 是否还需要 `from:` 这类手写操作符, 还是只保留结构化筛选?

## 当前默认

- 范围: 本地 Bleve 搜索; IMAP 账号用服务端搜索补未拉取邮件, POP3 只搜本地.
- 收件人: 同时匹配 To, Cc 和 Bcc.
- 本地归档: 包含在搜索结果, 结果带"本地归档"标识.
- 结构化筛选为主, 暂不要求用户手写操作符.
- 条件之间是 AND 关系; 中文使用 CJK 二元组.
