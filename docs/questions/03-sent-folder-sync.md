# 03 已发送拉取与草稿推送

## 已确认

- 已发送拉取做成设置项, 不写死.
- 草稿默认只保存在 MailQuay, 但从远端 Drafts 拉取.
- 草稿推送到上游需要用户在设置中主动开启, 避免频繁请求.

## 当前默认

- 已发送拉取默认开启.
- 副本模式 `auto`: 服务商自动复制时不追加, 其他情况由后端 `APPEND`.
- 草稿同步默认 `pull`: 低频拉取远端 Drafts, 不推送; `mirror` 才单向推送本地草稿.
- 不在已发送上回写标志, 移动和删除.
