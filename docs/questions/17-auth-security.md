# 17 登录方式与二次验证

## 已确认

- 目前只做用户名和密码登录.
- 明确不做邮箱绑定和邮件验证码.
- 主要功能完成后再做第三方 OAuth2 登录, 和邮箱账号的 OAuth2 是两套东西.

## 当前默认

- 登录: 用户名 + 密码, 不涉及邮箱验证.
- 二次验证: v1 不做 TOTP, 依赖强密码, setup token 和反代/VPN.
- 会话: 7 天滑动续期, 修改密码撤销全部会话.
- 初始化: 首次启动日志输出一次性 setup token, `/setup` 必须提交.
- 第三方 OAuth2 登录只预留设计, v1 不实现.
